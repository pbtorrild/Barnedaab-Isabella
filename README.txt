ISABELLAS BARNEDÅB - HTML INVITATION

Filer:
- index.html       GitHub Pages-version
- email.html       HTML-mail-version
- isabella.jpg     Billedet brugt i begge versioner

GitHub Pages:
1. Læg alle tre filer i roden af dit repository.
2. Aktivér GitHub Pages for repositoryet.
3. index.html virker direkte uden build-system.

HTML-mail:
- Mange mailklienter kan ikke hente et lokalt billede fra "isabella.jpg".
- Når GitHub Pages er publiceret, skift src="isabella.jpg" i email.html til den fulde offentlige URL til billedet.
- Google-fonten vises i mailklienter der understøtter webfonts. Andre klienter falder automatisk tilbage til Georgia/Arial.

- Nunito Sans til brødtekst
